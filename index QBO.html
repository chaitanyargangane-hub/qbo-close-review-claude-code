How it was run

Six prompts in Claude Code, working on a GitHub repository. Rules in CLAUDE.md stop it from posting anything, require evidence for every finding, and block it from calling an account reconciled until the difference is exactly zero.

  1. Read and summarise the files

    All four opening and closing balances matched the source files, including the two QBO balances it had to calculate.

  2. Reconcile checking

    Script matched statement to register on amount and date. Result: not reconciled, $629.00 difference, fully explained.

  3. Reconcile the Amex card

    $2,658.00 difference: a card payment booked as an expense, and a refund entered as a charge (2 × $129).

  4. Review transactions, AR and AP

    Fifteen findings with evidence. Claude raised two items beyond the reviewer's own list: unrecorded payroll withholdings and a possible annual Adobe plan.

  5. Stage approved corrections

    Ten balanced entries; both reconciliations re-run to zero. Items needing the client were left unstaged.

  6. Open questions and close status

    Client questions written up with file and line references; every prompt logged word for word.
